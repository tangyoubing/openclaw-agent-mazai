# OpenClaw TTS 语音功能技能包（共享）

## 内置TTS工具
- 工具名称：`tts`
- 用法：`tts: { text: "要说的内容" }`
- 自动生成语音并交付

## 支持的TTS提供商
| 提供商 | 特点 | 需要配置 |
|--------|------|----------|
| ElevenLabs | 高质量多语言 | API Key |
| 火山方舟 | 中文优化 | API Key（老板已有） |
| Azure TTS | 微软云服务 | API Key |
| 本地TTS | 免费离线 | 无需配置 |

## 调用示例
```
tts: { text: "老板您好，傻妞为您服务" }
```
