# 自我优化技能包（共享）

## 四层记忆架构
| 层级 | 存储 | 特点 |
|------|------|------|
| 工作记忆 | 上下文窗口 | 当前对话，有限容量 |
| 压缩摘要 | LCM数据库 | 历史会话压缩 |
| 持久文件 | MEMORY.md + memory/*.md | 长期存储 |
| 反思记忆 | reflective-memory.md | 决策质量分析 |

## 三大优化循环
### 1. 代码优化
```
执行任务 → 评估质量 → 诊断问题 → 改进策略 → 记录教训
```

### 2. 记忆优化
```
会话结束 → 摘要压缩 → 重要性评分 → 记忆蒸馏 → 归档清理
```

### 3. 搜索优化
```
语义搜索(memory_search) + 全文搜索(lcm_grep) + 结构化展开(lcm_expand)
```

## 错误学习机制
| 文件 | 作用 |
|------|------|
| corrections.md | 错误记录+修复方案 |
| tool-memory.md | 工具使用效果积累 |
| reflection-log.md | 决策复盘总结 |

## 三不原则
- 不重复犯同样错误（查corrections）
- 不丢失有效经验（写入memory）
- 不过度优化（80分即可，不追求100分）

## 定期维护
- 每3天：整理记忆文件
- 每周：清理过期内容
- 每月：归档冷数据
