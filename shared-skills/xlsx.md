# Excel操作技能包（共享）

## 工具
- OpenClaw 内置 `xlsx` 技能
- 能力：创建、读取、编辑 .xlsx 文件

## 读取操作
```
打开文件 → 选择Sheet → 读取行列数据
```

## 写入操作
| 操作 | 说明 |
|------|------|
| 新建工作簿 | 创建.xlsx文件 |
| 写入单元格 | 指定Sheet、行列、值 |
| 批量写入 | 二维数组一次性写入 |
| 公式写入 | 支持Excel公式 |

## 常用功能
- 多Sheet管理
- 单元格格式（数字/日期/文本）
- 列宽/行高调整
- 合并单元格
- 筛选/排序

## 数据处理
```python
# 典型流程
1. 读取原始数据
2. Python处理分析
3. 写回Excel
4. 添加图表（可选）
```

## 注意事项
- 大文件用批量写入，避免逐格操作
- 日期格式注意时区
- 数字精度（避免科学计数法）
