## 豆包 — AI对话助手

### 提示词框架（3步法）
1. **明确角色**：你是XX专家
2. **说明任务**：请帮我完成XX
3. **给出要求**：格式、长度、风格

### 模板示例
```
角色：你是一个资深文案策划
任务：帮我写一篇产品推广文案
要求：
- 突出产品核心卖点
- 语气亲切自然
- 300字以内
- 适合发朋友圈
```

### 核心能力
| 功能 | 用途 |
|------|------|
| 智能对话 | 问答、咨询 |
| 文案写作 | 报告、方案 |
| 资料搜集 | 信息整理 |
| 翻译润色 | 多语言处理 |
| Seedance视频 | AI视频生成 |

## 即梦 — AI图像/视频生成

### 提示词结构
```
主体 + 风格 + 场景 + 细节
```

### 示例
```
一个年轻女性，职业形象照风格，
办公室背景，微笑，穿正装，
高质量，专业摄影
```

### 能力范围
- 商品海报生成
- 宣传图设计
- 职业形象照
- 卡通形象
- 视频生成

## 扣子（Coze）— AI智能体平台

### 基本信息
- 字节跳动出品，无需编程开发AI应用
- 网站：coze.cn

### 核心功能
| 功能 | 说明 |
|------|------|
| 智能体创建 | 配置人设、能力、知识库，一键发布多平台 |
| 工作流 | 可视化流程设计，连接多个AI能力 |
| 插件系统 | 内置商店，连接外部API |
| 知识库 | 上传文档，RAG检索增强 |

### 应用场景
| 场景 | 示例 |
|------|------|
| 自动写公文 | 模板自动生成 |
| 客户分析 | 反馈数据分析 |
| 公众号漫画 | 漫画工作流 |
| 陪伴助手 | AI女友/心理咨询 |
| 学习助手 | 出题、答疑 |

### vs 传统开发
| 对比项 | 扣子 | 传统开发 |
|--------|------|----------|
| 编程要求 | 无需 | 需要 |
| 开发时间 | 分钟级 | 天级 |
| 维护成本 | 低 | 高 |

### 使用步骤
1. 登录 coze.cn
2. 创建Bot
3. 配置人设和提示词
4. 添加插件/知识库
5. 设计工作流
6. 测试发布
