# 前端设计技能包（共享）

## 工具
- OpenClaw 内置 `frontend-design` 技能
- 支持 HTML/CSS/JS 单页应用

## 设计流程
```
理解需求 → 选配色 → 建布局 → 填内容 → 交互优化
```

## 核心能力
| 能力 | 说明 |
|------|------|
| 页面布局 | Flexbox/Grid 响应式 |
| 配色方案 | 主色+辅色+背景色 |
| 组件设计 | 按钮/卡片/表单/导航 |
| 动画交互 | CSS过渡/关键帧动画 |
| 数据展示 | 图表/列表/仪表盘 |

## 常用框架
- **CSS框架**：Tailwind CSS（实用优先）
- **图标库**：FontAwesome / Heroicons
- **图表库**：Chart.js / ECharts

## 设计原则
- 移动端优先（响应式）
- 留白充分（呼吸感）
- 色彩克制（主色≤3种）
- 字体层级（标题→正文→辅助）

## 交付物
- 单页 HTML 文件（自包含）
- 嵌入 iframe 预览
- 可部署到静态托管

## 注意事项
- 避免外部CDN依赖（墙的问题）
- 内联CSS/JS确保离线可用
- 图片用base64或本地引用
