# Word文档操作技能包（共享）

## 工具
- OpenClaw 内置 `docx` 技能
- 能力：创建、读取、编辑 .docx 文件

## 创建文档
```
# 基本结构
标题 → 段落 → 表格 → 图片
```

## 常用操作
| 操作 | 说明 |
|------|------|
| 新建文档 | 指定标题和内容 |
| 读取内容 | 解析段落、表格、样式 |
| 插入段落 | 追加文字段落 |
| 插入表格 | 行列数据写入 |
| 格式设置 | 字体、颜色、对齐 |

## Markdown → Word
- 支持 Markdown 转 Word
- 标题 → Heading 样式
- 列表 → 项目符号/编号
- 表格 → Word 表格

## 注意事项
- 中文字体兼容（宋体/微软雅黑）
- 分页控制用分节符
- 模板文档可复用样式
