# 云存储备份技能包（共享）

## 工具
| 工具 | 能力 |
|------|------|
| `cloud-upload-backup` | 云上传备份 |
| `bdpan-storage` | 百度网盘操作 |
| `weiyun` | 微云操作 |

## 备份策略
```
本地文件 → 打包 → 上传云端 → 记录链接
```

## 常用操作
| 操作 | 说明 |
|------|------|
| 上传文件 | 单文件/文件夹上传 |
| 分享链接 | 生成分享链接 |
| 批量备份 | 定时自动备份 |
| 增量同步 | 只传变更文件 |

## 备份内容
- 工作区重要文件
- 项目代码仓库
- 配置文件
- 记忆文件（memory/*）

## 三点备份原则
```
1 本地副本（工作区）
2 云端备份（百度网盘/微云）
3 远程仓库（Git）
```

## 注意事项
- 敏感文件加密后上传
- 定期检查云端文件完整性
- 超过100MB的大文件分卷压缩
- 注意云盘空间配额
