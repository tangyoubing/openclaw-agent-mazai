# PDF操作技能包（共享）

## 工具
- OpenClaw 内置 `pdf` 技能
- 能力：读取、创建、转换 PDF

## 读取PDF
- 提取文字内容
- 解析表格数据
- 获取页面信息

## 创建PDF
- Markdown → PDF
- HTML → PDF
- 自定义页面尺寸

## 常用场景
| 场景 | 方法 |
|------|------|
| 提取合同文字 | 读取PDF → 输出文本 |
| 发票数据提取 | 解析PDF表格 |
| 生成报告 | Markdown写入 → 导出PDF |
| 合并多文件 | 逐页追加 |

## 注意事项
- 扫描件PDF需要OCR
- 加密PDF需要密码
- 中文字体嵌入避免乱码
