# PPT操作技能包（共享）

## 工具
- OpenClaw 内置 `pptx` 技能
- 能力：创建、编辑、读取 .pptx 文件

## 创建流程
```
选模板 → 建幻灯片 → 填内容 → 调样式
```

## 幻灯片结构
| 元素 | 说明 |
|------|------|
| 标题 | 每页主标题 |
| 正文 | 要点/段落文字 |
| 图片 | 插图、图表截图 |
| 表格 | 数据展示 |

## 常用操作
- 新建PPT（指定模板或空白）
- 添加幻灯片
- 插入文本框
- 插入图片/图表
- 设置主题配色

## Markdown → PPT
```
# 一级标题 = 新幻灯片标题
## 二级标题 = 小标题
- 列表 = 要点
```

## 设计建议
- 每页 ≤ 5个要点
- 字号 ≥ 18pt
- 图片优先于文字
- 配色统一
