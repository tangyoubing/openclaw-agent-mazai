# 剪映视频剪辑技能包（共享）

## 安装位置
- **路径**: D:\剪映\JianyingPro\
- **版本**: 5.5.0.11332

## 基础流程
1. 导入素材 → 2. 粗剪 → 3. 精剪 → 4. 字幕 → 5. 特效 → 6. 调色 → 7. 音频 → 8. 导出

## 常用快捷键
| 操作 | 快捷键 |
|------|--------|
| 播放/暂停 | 空格 |
| 分割 | Ctrl+B |
| 删除 | Delete |
| 撤销 | Ctrl+Z |
| 导出 | Ctrl+E |
| 复制属性 | Ctrl+C → Ctrl+V |
| 预览全屏 | F |
| 缩放时间线 | Ctrl+滚轮 |
| 吸附开关 | S |
| 批量选择 | Shift+点击 |

## 输出格式
- 分辨率: 1080P/4K
- 帧率: 30/60fps
- 格式: MP4

## 关键帧动画
- 添加关键帧：选中素材 → 右键 → 添加关键帧
- 关键帧类型：位置、缩放、旋转、透明度
- 曲线编辑器：右键关键帧 → 曲线 → 自定义缓动

## 曲线变速
- 变速：选中片段 → 右键 → 变速/持久
- 曲线变速：变速 → 曲线 → 贝塞尔曲线
- 常规预设：匀速、慢动作、快动作、倒放

## 蒙版功能
- 蒙版类型：矩形、圆形、线性、镜像、绘制
- 羽化：边缘柔化程度
- 蒙版动画：添加关键帧 → 移动蒙版

## 调色技巧
- 基础调色：亮度、对比度、饱和度、光感、暗部、色彩
- 曲线调色：RGB曲线、色相曲线
- LUT调色：预设调色文件加载
- 风格化：电影感、复古、胶片

## 转场效果
- 基础转场：叠化、闪黑、闪白
- 运镜转场：推拉、旋转、缩放
- 特效转场：光晕、故障、毛边

## 音频处理
- 音效：环境音、动作音、转场音
- 变声：机器人、卡通、外星人
- 踩点：自动踩点 → 批量添加特效

## 智能功能
- 智能补帧：60帧插帧
- 智能抠像：人物背景分离
- 自动字幕：语音识别 → 字幕生成

## 项目结构
- 草稿文件：.jianying4
- 缓存目录：Drafts
- 素材库：本地素材、云素材
