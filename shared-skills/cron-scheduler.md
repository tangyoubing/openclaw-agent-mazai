# 定时任务技能包（共享）

## 工具
- OpenClaw 内置 `cron` 工具
- 支持一次性 + 周期性任务

## 任务类型
| 类型 | 说明 | 示例 |
|------|------|------|
| at | 一次性定时 | "明天9点提醒开会" |
| every | 固定间隔 | "每30分钟查邮件" |
| cron | 周期表达式 | "每天8点日报" |

## Cron表达式
```
分 时 日 月 周
0  8  *  *  *    → 每天8点
0  9  *  *  1-5  → 工作日9点
*/30 * * * *     → 每30分钟
```

## 常用场景
```javascript
// 每日整理
cron: "0 3 * * *" → 凌晨3点记忆整理

// 定时检查
cron: "0 */2 * * *" → 每2小时检查状态

// 一次性提醒
at: "2026-05-20T15:00:00+08:00" → 指定时间
```

## 两种运行模式
| 模式 | 说明 |
|------|------|
| main session | 注入系统事件（轻量） |
| isolated session | 独立会话执行（完整） |

## 最佳实践
- 每日任务放凌晨低峰期
- 避免整点（错开高峰）
- 超时设置合理（≤5分钟）
- 失败有告警通知
