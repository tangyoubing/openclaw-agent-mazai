# 邮件操作技能包（共享）

## 工具
- OpenClaw 内置 `email-skill`
- 协议：IMAP（收）+ SMTP（发）

## 读取邮件
```
# 查收件箱
- 获取未读邮件
- 搜索特定发件人/主题
- 查看邮件正文+附件
```

## 发送邮件
```
# 发邮件
收件人 → 主题 → 正文 → 附件(可选)
```

## 常用操作
| 操作 | 说明 |
|------|------|
| 查未读 | 获取未读邮件列表 |
| 标记已读 | 阅读后标记 |
| 回复邮件 | 引用原邮件 |
| 删除/归档 | 清理收件箱 |

## 邮件规则
- 紧急邮件 → 及时通知老板
- 广告/订阅 → 静默处理
- 附件 → 下载到工作区

## 配置说明
- IMAP服务器 + 端口
- SMTP服务器 + 端口
- 邮箱账号 + 授权码（非登录密码）

## 注意事项
- 授权码 ≠ 邮箱密码
- QQ邮箱需开启IMAP/SMTP服务
- 发送频率限制，避免被判定垃圾邮件
