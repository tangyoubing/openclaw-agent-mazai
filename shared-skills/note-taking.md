# 多平台笔记操作技能包（共享）

## 支持的平台
| 平台 | 技能 | 特点 |
|------|------|------|
| 有道云笔记 | `youdaonote` | 国内最常用 |
| Notion | `notion` | 国际化数据库 |
| 飞书文档 | `feishu_doc` | 企业协作 |
| 腾讯文档 | `tencent-docs` | 微信生态 |
| 知识库 | `ima` | AI驱动 |

## 通用操作
```
创建文档 → 写入内容 → 格式化 → 分享/导出
```

## 平台选择建议
| 场景 | 推荐 |
|------|------|
| 个人笔记 | 有道云笔记 |
| 项目管理 | Notion |
| 团队协作 | 飞书文档 |
| 客户分享 | 腾讯文档 |
| AI辅助 | IMA |

## 内容格式
- Markdown 通用格式
- 表格/列表/图片 全支持
- 代码块高亮

## 同步策略
- 重要内容多平台备份
- 本地优先 → 云端同步
- 定期检查链接有效性

## 注意事项
- 不同平台Markdown渲染差异
- API频率限制
- 敏感内容加密存储
