## 三、AI长期记忆管理优化 2026

1. **MEMMA系统（宾州大学+Amazon+MS）** — 多智能体协作管理记忆，三步闭环：构建（决定记什么）→ 检索（快速找到相关记忆）→ 利用（用记忆回答问题），第三步反馈优化前两步。

2. **OpenClaw Dreaming三阶段** — 浅睡(摄入排序)→REM(反思提取)→深睡(升级到MEMORY.md)，必须通过三个阈值门限(minScore 0.8 / minRecallCount 3 / minUniqueQueries 3)，加权信号评分。

3. **MemPalace** — 反传统思路：不删减不摘要，保留完整对话存入ChromaDB，靠结构化检索找回。不替用户决定什么重要。

4. **工业级四层记忆架构**：短期记忆(上下文窗口) → 长期记忆(向量库+结构化DB) → 外部记忆(RAG/知识库) → 反思记忆(决策质量分析)
