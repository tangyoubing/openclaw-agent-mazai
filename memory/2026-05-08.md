### 22:40  -  飞书多Agent群聊方案确定

- 分析了 OpenClaw channels schema，确认飞书(feishu)是最佳方案
- 飞书优势：国内可用无需VPN、支持多账号(accounts配置)、群聊功能完善、OpenClaw原生支持
- 其他平台对比：Discord(需VPN)可行但不如飞书方便、企业微信(待确认)、QQ Bot(AIGC限制不能加群)
- 决定用 **WebSocket连接模式**（不需要公网IP/域名）
- 飞书channel必填字段：domain, connectionMode, webhookPath, dmPolicy, groupPolicy, reactionNotifications, typingIndicator
- 每个account需要：appId, appSecret, verificationToken, encryptKey
- 群聊中用 requireMention: true 控制各Bot只在被@时回复
- 先用码仔+浣熊2个现有Agent跑通，后续再加作家、贾维斯
- 已指导用户去 https://open.feishu.cn 创建企业自建应用，等用户提供App ID/Secret等信息后继续配置
- binding模式：{ "agentId": "agent-113ca7a4", "match": { "channel": "feishu", "accountId": "mazai_app_id" } }
